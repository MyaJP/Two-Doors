# Two Doors

A data pack: door recipes make **2 doors instead of 3**.

- All wooden doors, the Iron Door and the Copper Door
- Minecraft 1.13 – 26.3 in one file (pack overlays for the newer recipe formats)

**Install:** put the zip in your world's `datapacks` folder, then run `/reload`.

On versions before 1.16 the log may show errors for doors that don't exist yet (Crimson, Cherry and so on). They are harmless. Waxed and oxidized copper doors are not changed (they have no 3-door recipe in vanilla).

`pack/` holds the data pack and `VERSION` its version. The Publish workflow zips it and uploads it to Modrinth and CurseForge.
